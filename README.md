# college-grading-system

College Grading System application.

## Overview
A web-based College Grading System to manage students, calculate grades, and track academic performance.

## Project Structure
- `frontend/` - React (JSX) frontend application built with Vite.

## Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Running the Frontend
```bash
cd frontend
npm install
npm run dev
```
