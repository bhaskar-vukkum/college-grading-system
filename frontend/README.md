# Frontend - College Grading System

This is the frontend client for the **College Grading System**, built with plain React (JSX) and Vite.

## Features
- **Student Grade Entry**: Input student roll number, name, course name, credit hours, and score.
- **Dynamic GPA & Grade Calculation**: Automatic conversion to letter grades (A+, A, B, C, D, F) and standard 4.0 grade points.
- **Academic Dashboard**: High-level metrics showing total records, average GPA, average percentage score, and overall passing rate.
- **Live Search & Filter**: Filter grades by subject and search records by roll number or name.

## Scripts

### 1. Install dependencies
```bash
npm install
```

### 2. Start development server
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```
